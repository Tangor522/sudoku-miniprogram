# 数独小勇士 - 微信小程序

由 React + Tailwind 数独游戏迁移而来的微信原生小程序（WXML/WXSS/JS），支持四宫格、六宫格和标准九宫格、100 关进阶、三套配色、微信一键登录。

## 功能

- 🦄 四宫格（2×2 宫）、六宫格（2×3 宫）和九宫格（3×3 宫）
- 📚 各 100 关，空格数随关卡递增；所有新生成题目保证唯一解
- 🎮 保留纯粹玩法：手动开始、选格填数、提交检查、重置
- 🎨 三套配色：粉色 / 柔和绿 / 护眼橙
- ⏱️ 计时统计，记录每关最佳成绩
- 🔐 微信一键登录（点一下即可，无需扫码）

## 一、导入项目

1. 打开**微信开发者工具**
2. 选择「导入项目」
3. 项目目录：选择 `sudoku-miniprogram` 文件夹
4. AppID：填入你的小程序 AppID
   - 同时把 `project.config.json` 里的 `"appid": "请替换为你的AppID"` 改成你的真实 AppID
5. 点击导入

## 二、两种运行模式

### 模式 A：本地存储模式（开箱即用，无需任何配置）

保持 `app.js` 中 `cloudEnv: 'your-env-id'` 不变即可，小程序立即可运行：

- 登录用本地生成的临时用户标识
- 游戏进度存在小程序本地缓存
- ⚠️ 缺点：换设备不同步、清缓存会丢失、头像为临时路径（关闭小程序后失效）

**适合**：先快速体验效果，或只在单设备玩。

### 模式 B：云开发模式（推荐，跨设备同步）

开通后登录用真实微信身份、成绩自动同步云端、换设备也能看到记录。

#### 1. 开通云开发
- 在开发者工具顶部点击「云开发」按钮，按提示开通并创建一个云环境
- 记下**云环境 ID**

#### 2. 替换云环境 ID
打开 `app.js`，把：
```js
cloudEnv: 'your-env-id'
```
改成你的真实云环境 ID，例如：
```js
cloudEnv: 'cloud1-2g5abc...'
```

#### 3. 部署云函数
- 在开发者工具左侧目录树，右键 `cloudfunctions/login` 文件夹 →「上传并部署：云端安装依赖」
- 对 `cloudfunctions/saveProgress` 做同样操作
- 对 `cloudfunctions/getRanking` 做同样操作（排行榜功能需要）
- 等待右下角提示「上传成功」

#### 4. 创建数据库集合并设置权限
- 进入云开发控制台 → 数据库 → 新建两个集合：
  - `users`（用户资料）
  - `progress`（关卡成绩）
- 每个集合点「权限设置」→ 选择「**仅创建者可读写**」（自动按 openid 隔离不同用户）

#### 5. 重新编译运行
现在登录会调用云函数换取 openid，成绩自动同步云端。

## 三、真机调试注意事项

- 头像昵称填写能力（`chooseAvatar` + `nickname input`）需基础库 **≥ 2.21.2**
- 开发者工具里 `nickname input` 的微信昵称自动填充可能异常，请以**真机预览**为准
- iOS 上昵称输入用 `bindblur` 取值（代码已处理）
- 头像临时路径（`wxfile://`）关闭小程序即失效；云开发模式下会自动上传云存储换永久 fileID
- 本地存储模式下，头像仅在本次会话有效

## 四、目录结构

```
sudoku-miniprogram/
├── app.js / app.json / app.wxss      # 入口、全局配置、三套主题 CSS 变量
├── pages/
│   ├── home/        # 首页：模式选择、配色切换、用户信息
│   ├── login/       # 微信一键登录 + 首次资料补全
│   ├── game4x4/     # 四宫格游戏（2×2 宫，1-4，100 关）
│   ├── game6x6/     # 六宫格游戏（2 行 3 列宫，1-6，100 关）
│   ├── game9x9/     # 标准九宫格（3×3 宫，1-9，100 关、唯一解）
│   ├── stats/       # 游戏记录表格
│   └── ranking/     # 玩家排行榜（总关数 + 总用时）
├── utils/
│   ├── sudoku.js    # 通用数独算法：终盘生成、唯一解挖空、求解、校验
│   ├── game-page.js # 三种单人模式共用的交互与生命周期控制器
│   ├── store.js     # 全局状态管理（globalData + 发布订阅）
│   ├── theme.js     # 主题切换
│   ├── timer.js     # 计时器（后台暂停、回前台恢复）
│   ├── storage.js   # 本地存储封装（降级方案）
│   ├── cloud.js     # 云开发封装（推荐方案）
│   └── auth.js      # 登录鉴权
└── cloudfunctions/
    ├── login/            # 换 openid、首次注册、更新资料
    ├── saveProgress/     # 保存/查询关卡成绩
    └── getRanking/       # 排行榜：聚合统计玩家总关数、总用时
```

## 五、从原 React 代码的迁移对照

| 原 React | 小程序实现 |
|---|---|
| `currentPage` 状态路由 | 多 page 跳转（wx.navigateTo） |
| `useState` | page `data` + `setData` |
| `localStorage` | `wx.setStorageSync` / 云数据库 |
| Tailwind 原子类 | WXSS（CSS 变量做三套主题切换） |
| 用户名密码登录 | 微信一键登录（云函数 openid） |
| `useEffect + setInterval` 计时器 | `utils/timer.js`（生命周期管理，后台暂停） |
| `getColorTheme()` 返回 Tailwind 类 | CSS 变量 + `theme-xxx` 根节点 class |
| 条件渲染弹窗 | `wx:if` + `.mask` 遮罩 |

## 六、常见问题

**Q：登录页点「微信一键登录」没反应？**
A：检查是否已部署 `login` 云函数，或临时用本地存储模式（保持 `cloudEnv` 为 `your-env-id'`）先体验。

**Q：头像保存后下次打开不见了？**
A：本地存储模式下头像是临时路径，关闭即失效。开通云开发后会自动上传云存储永久保存。

**Q：成绩没同步到新手机？**
A：确认已开通云开发并部署了 `saveProgress` 云函数，且 `progress` 集合权限设为「仅创建者可读写」。
