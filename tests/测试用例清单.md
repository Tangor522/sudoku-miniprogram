# 数独小程序 - 测试用例清单

> 本清单用于在**微信开发者工具**或**真机预览**中手动执行，覆盖功能、边界、异常、体验四类场景。
> 执行时在「测试结果」列填 ✅ 通过 / ❌ 失败 / ⚠️ 有疑虑。

---

## 一、登录流程（login 页）

| 编号 | 场景 | 操作步骤 | 预期结果 | 测试结果 |
|---|---|---|---|---|
| L-01 | 本地模式一键登录 | 保持 `cloudEnv='your-env-id'`，点「微信一键登录」 | 进入资料补全页，提示「未开通云开发」 | |
| L-02 | 资料补全-选头像 | 点头像区域 → 选择相册/拍照图片 | 头像显示为所选图片 | |
| L-03 | 资料补全-填昵称 | 在昵称输入框输入文字（iOS 真机） | 键盘上方出现微信昵称快捷填充；输入框显示文字 | |
| L-04 | 资料补全-空昵称保存 | 不填昵称直接点「保存并进入」 | Toast 提示「请输入昵称」 | |
| L-05 | 资料补全-正常保存 | 填昵称 + 选头像 → 保存 | 跳转首页，首页显示昵称和头像 | |
| L-06 | 跳过资料补全 | 点「跳过，稍后设置」 | 跳转首页，头像显示首字母占位 | |
| L-07 | 云开发模式登录 | 配置真实 env id + 部署 login 云函数后点登录 | 云函数返回 openid，进入首页或资料补全 | |
| L-08 | 云函数失败降级 | 云开发模式下断网后点登录 | 降级本地模式，仍可进入（控制台有错误日志） | |
| L-09 | 登录态保持 | 登录后关闭小程序再打开 | 直接进首页，无需重新登录 | |

## 执行说明

1. **本地模式测试**：保持 `app.js` 中 `cloudEnv='your-env-id'`，直接导入开发者工具即可测 L-01~L-06、全部 H/G/S/E/C/P 用例
2. **云开发模式测试**：按 README 开通云开发后，重点测 L-07~L-09、S-07、E-10
3. **真机测试**：L-03（昵称）、C-01/C-02 必须真机，开发者工具模拟不可靠
4. **边界测试**：E-01~E-04 可临时在 `game4x4.js` 的 `onLoad` 里改 `level` 值快速验证
